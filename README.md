# Google Advanced Data Analytics Portfolio 🚀

Chào mừng đến với kho lưu trữ các dự án và tài liệu thực hành của tôi trong quá trình hoàn thành chứng chỉ **Google Advanced Data Analytics** trên Coursera.

## 📌 Mục tiêu
Kho lưu trữ này tài liệu hóa toàn bộ hành trình tôi áp dụng các kỹ năng Data Science vào giải quyết các bài toán kinh doanh. Các dự án ở đây thể hiện tư duy làm việc end-to-end: từ việc lên kế hoạch dự án, tiền xử lý dữ liệu, cho đến xây dựng các mô hình Machine Learning dự đoán.

## 📂 Cấu trúc Kho lưu trữ
* **`Course_1_Foundations/`**: Các tài liệu nền tảng, quy trình quản lý dự án dữ liệu, khung làm việc PACE (Plan - Analyze - Construct - Execute) và kỹ năng giao tiếp.
* **`Course_2_Python_for_Data_Science/`**: *(Sắp cập nhật)*
* **`assets/`**: Lưu trữ hình ảnh báo cáo, sơ đồ và chứng chỉ.

## 🛠️ Công cụ & Kỹ năng
* **Ngôn ngữ & Thư viện:** Python (Pandas, NumPy)
* **Quy trình làm việc:** PACE Framework
* **Kỹ năng mềm:** Trình bày tóm tắt điều hành (Executive Summary), Giao tiếp với các bên liên quan (Stakeholders).
